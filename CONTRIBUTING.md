# Как поучаствовать

*English: this project accepts contributions in both Russian and English —
write in whichever you are comfortable with.*

Самый ценный вклад — **рабочий пресет**. Стратегии обхода протухают, у каждого
провайдера свои особенности, и один человек физически не может покрыть все сети.

## Прислать пресет

### 1. Найди рабочую стратегию

```console
$ sudo blockcheck2
```

`blockcheck2` идёт в пакете `zapret2` и перебирает стратегии против реально
заблокированных ресурсов на твоём канале. Запиши то, что заработало.

### 2. Опиши её как пресет

Создай `presets/<имя>.nix`. Пресет — это **чистые данные**, никакого кода:

```nix
{
  description = "Коротко: что именно чинит пресет";

  meta = {
    testedOn = [ "Ростелеком" "МТС" ];   # где подтверждённо работает
    lastVerified = "2026-07-27";          # ГГГГ-ММ-ДД
    reference = "https://...";            # необязательно: откуда стратегия
  };

  hostlist = [ "example.com" ];           # домены (поддомены — автоматически)

  profiles = [{
    filter = { tcp = "443"; l7 = [ "tls" ]; };
    payload = [ "tls_client_hello" ];
    desync = [
      "fake:blob=fake_default_tls:tcp_md5"
      "multisplit:pos=1"
    ];
  }];
}
```

Полный список полей с описаниями — в [`lib/types.nix`](lib/types.nix).
Значения `filter`, `payload` и `desync` — это термины самого zapret2, их
список выдаёт `nfqws2 --help`.

### 3. Проверь

```console
$ nix flake check
```

Проверка прогонит твой пресет через контракт **и через настоящий `nfqws2`** —
опечатка в имени опции будет поймана сразу, а не всплывёт у пользователя в
виде «обход не работает».

### 4. Открой PR

В описании укажи:

- **провайдера и регион** — без этого пресет невозможно оценить;
- **что именно проверял** (какие сайты/сервисы заработали);
- если пресет — вариация существующего, объясни, чем отличается и почему
  нельзя обойтись имеющимся.

## Чего лучше не делать

- **Не присылай пресет «на всякий случай»**, если сам его не проверял.
  Непроверенный пресет хуже отсутствующего: человек потратит время, решит что
  проект не работает, и уйдёт.
- **Не плоди почти одинаковые варианты.** Если отличие в одном параметре —
  вероятно, стоит дополнить существующий пресет, а не заводить `_ALT_v7`.
- **Не хардкодь сырые аргументы в `extraArgs`**, если под них есть поле.
  `extraArgs` — аварийный люк; если ты им пользуешься постоянно, заведи issue,
  добавим нормальное поле.

## Устаревшие пресеты

Поле `meta.lastVerified` существует именно для этого: по нему видно, насколько
пресету можно доверять. Если пресет перестал работать — **это тоже вклад**,
открой issue. Лучше честно пометить пресет как протухший, чем оставить
пользователя гадать.

## Код

Правки в модуле и библиотеке тоже приветствуются. Границы, которые стоит
уважать:

| Слой | Ответственность | Не должен знать про |
|---|---|---|
| `presets/` | что делать с трафиком | systemd, firewall |
| `lib/` | контракт пресета и рендер | систему целиком |
| `modules/zapret2.nix` | жизненный цикл службы | конкретные стратегии |
| `modules/firewall.nix` | доставку пакетов в NFQUEUE | Lua и стратегии |

Форматирование: `nix fmt`.
